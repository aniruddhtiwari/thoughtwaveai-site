Getting Started

Set up once. Prepare with purpose each time.

ThoughtWaveAI is currently available through a controlled Windows desktop beta. This guide separates initial setup from the short routine you use before every session.

AOne-Time SetupInstall and configureBBefore Each SessionPrepare the conversation

A · One-Time Setup

Get ThoughtWaveAI ready.

Complete these steps when you first receive the Windows beta, then revisit them only when your configuration changes.

Install ThoughtWaveAI

Follow the beta installation instructions provided with your Windows build.

Configure your model provider

Complete the required AI provider configuration in Settings. Keep credentials private and enter them only in the app.

Grant audio permissions

Allow the microphone and system-audio access required for your intended conversation setup.

Confirm required audio sources

Run an audio check and confirm ThoughtWaveAI can hear the sources you plan to use. Device and meeting-app behavior can vary.

Choose display and privacy preferences

Set window placement, opacity, screen visibility, language, and other user-facing defaults as needed.

Connect Mobile Companion if desired

Use the connection option from the active desktop session when a lightweight phone view would be useful.

Recommended starting point

Screen visibilityPrivate
InfluenceMedium
Mobile CompanionOff until needed
Advanced settingsKeep defaults unless required

B · Before Each Session

Prepare the conversation.

For most sessions, Outcome, Influence, and Session Context are the essential inputs. Together, they help ThoughtWaveAI anticipate useful questions, likely follow-ups, and important points to consider.

Set Outcome

What do you want to achieve in this conversation?

Set Influence

Choose how strongly assistance should support the outcome: Low, Medium, or High.

Add Session Context

Add relevant notes, facts, constraints, concerns, and supported files.

Review optional settings

Adjust windows, opacity, privacy, Mobile Companion, profile, skill, or language settings where needed.

Start

Begin when the session guidance and context are ready.

Outcome and Influence guide assistance. Session Context provides the information used to ground relevant intelligence.

Practical examples

Use the same model in different rooms.

Keep preparation short, concrete, and tied to the result you need.

Leadership Meeting

Outcome

Get approval for my proposed architecture.

Influence

High

Session Context

Leadership review. Main concerns are scalability, cost, and implementation risk. I want to advocate for a phased rollout.

Sales Call

Outcome

Move the prospect to the next step in the sales process.

Influence

High

Session Context

The prospect is concerned about pricing, implementation effort, and timing. Understand the objection, address it clearly, and seek agreement for a follow-up demo or proposal review.

Negotiation / Interview

Outcome

Reach a favorable outcome while representing my position clearly and credibly.

Influence

Medium

Session Context

High-stakes discussion where I need to respond thoughtfully, address objections, strengthen my positioning, and avoid unsupported claims.

During the session

Choose the right kind of help.

Not just answers. Better questions—suggested when they may help move the conversation forward.

01

Discussion

Follow the shared conversational timeline.

02

Ask TW

Use the explicit path when you already have a question.

03

Assist

Continue from the recent conversation and consider a useful next question, follow-up, clarification, or point to raise.

04

TW Intelligence Assist

Receive a proactively surfaced question or point when the discussion indicates it may help.

05

Mobile Companion

Use Context, Assist, Discussion, and the persistent Ask TW composer from the same active session.

After the session

Return to the conversation first, then preserve the output you need.

Review
