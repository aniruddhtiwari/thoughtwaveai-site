Getting Started

Set up once. Prepare with purpose each time.

ThoughtWaveAI is currently available through a controlled desktop beta for Windows and macOS. This guide separates initial setup from the short routine you use before every session.

AOne-Time SetupInstall and configureBBefore Each SessionPrepare the conversation

A · One-Time Setup

Get ThoughtWaveAI ready.

Complete these steps when you first receive the desktop beta, then revisit them only when your configuration changes.

Install ThoughtWaveAI

Follow the beta installation instructions provided for your Windows or macOS build.

Configure your model provider

Complete the required AI provider configuration in Settings. Keep credentials private and enter them only in the app.

Grant audio permissions

Allow the microphone and system-audio access required for your intended conversation setup.

Confirm required audio sources

Run an audio check and confirm ThoughtWaveAI can hear the sources you plan to use. Device and meeting-app behavior can vary.

Choose display and privacy preferences

Set window placement, opacity, screen visibility, language, and other user-facing defaults as needed.

Connect Mobile Companion if desired

Use the connection option from the active desktop session when a lightweight phone view would be useful.

B · Before Each Session

Prepare the conversation.

Outcome, Influence, and Session Context help ThoughtWaveAI anticipate useful questions, likely follow-ups, and important points.

Set Outcome

Define what you want to accomplish.

Set Influence

Choose how strongly guidance should help move the conversation toward your Outcome.

Add Session Context

Add the notes, facts, constraints, and supported files that matter.

Review optional settings

Adjust privacy, display, Mobile Companion, profile, skill, or language settings if needed.

Start

Begin when your guidance and context are ready.

Outcome and Influence guide assistance. Session Context grounds it in the information you select.

Supported Session Context formats
  • TXT / Markdown
  • PNG / JPG / JPEG
  • PDF
  • DOCX
  • PPTX
  • CSV
  • XLS / XLSX
